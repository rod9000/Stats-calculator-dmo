# Plano: Melhorias de Código e Performance

## Problemas Identificados

### 1. Escopo Global (app.js)
- `escapeHtml()` e `copyResults()` estão FORA de `initApp()` — poluem o escopo global
- Linhas 7-22: funções soltas

### 2. Inconsistência var/const (app.js)
- `state` usa `const` (linha 26), `$` e `$$` usam `const` (linhas 33-34)
- Todo o resto usa `var` — mistura de estilos

### 3. DOM queries repetidas
- `$('#cloneLevel')` consultado múltiplas vezes sem cache
- `$$('input[name="calc-mode"]')` re-executado em listeners separados
- `$('#sealBody')` e `$('#listBody')` rebuscados em cada render

### 4. Falta debounce em buscas
- Autocomplete (linha 77) dispara a cada keystroke sem debounce
- Seal browser search (linha 939) idem
- D-Unit search (linha 1510) idem

### 5. Validação de inputs ausente
- Campos numéricos aceitam strings vazias/NaN sem tratamento consistente
- `parseNum()` retorna 0 para NaN — pode mascarar erros

### 6. Event listeners duplicados
- `renderSealBrowser()` (linha 907) adiciona event listener no `tbody` a cada render — memory leak potencial

### 7. localStorage sem try/catch consistente
- Alguns saves usam try/catch, outros não

### 8. CSS: variáveis não usadas
- `--panel-bg` definido mas subutilizado em alguns componentes

## Alterações a fazer

### `web/app.js`

1. **Mover funções globais para dentro de `initApp()`**
   - Mover `escapeHtml()` e `copyResults()` para dentro de `initApp()`

2. **Adicionar debounce simples**
   ```js
   function debounce(fn, ms) {
     var t; return function() { var a=arguments, c=this; clearTimeout(t); t=setTimeout(function(){ fn.apply(c,a); }, ms); };
   }
   ```
   - Aplicar no autocomplete input (300ms)
   - Aplicar no seal search (200ms)
   - Aplicar no D-Unit search (200ms)

3. **Corrigir memory leak no seal browser**
   - Usar event delegation no `document` ou mover listener para fora de `renderSealBrowser()`
   - Ou melhor: declarar o listener uma única vez e usar closure

4. **Unificar estilo para `var`** (consistente com o resto do códigobase)

5. **Cache de DOM refs**
   - Criar `var cloneLevelEl = $('#cloneLevel')` etc. no início de cada seção
